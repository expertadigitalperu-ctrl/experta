# Experta — Portafolio

Sitio oficial de Experta. Software, inteligencia artificial, automatización y gestión de datos.

## Publicación

Sitio estático preparado para GitHub Pages. Publicar desde la raíz de la rama `main`.
Todos los recursos locales usan rutas relativas compatibles con un repositorio de proyecto.

## Contacto y redes

Los enlaces oficiales y el número de WhatsApp se configuran en `site-config.js`.
El formulario prepara el mensaje para WhatsApp; no almacena consultas en el sitio.
